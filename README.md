# Phishing Website Detection using URL-Based Feature Analysis

## Project Overview

A machine learning-based web application that detects phishing websites using URL lexical features.

## Features

- URL Feature Extraction
- Machine Learning Classification
- Real-time Prediction
- Web Interface

## Tech Stack

- Python
- Flask
- Scikit-learn
- HTML
- CSS
- JavaScript
